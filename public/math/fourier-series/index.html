About
Period L = b − a. The series is SN(x) = a₀/2 + Σ[ancos(nωx) + bnsin(nωx)] with ω = 2π/L and coefficients computed by numerical integration of f over [a, b].

Supported in f(x):
Trig: sin, cos, tan, asin, acos, atan, atan2
Hyperbolic: sinh, cosh, tanh
Exp / log: exp, log, log2, log10
Roots: sqrt, cbrt
Numeric: abs, sign, floor, ceil, round, min, max, pow
Constants: pi, e
Operators: + − × / % ^ ( ) < > <= >= == != ?: && ||

Indicator functions like (abs(x)<1)?1:0 are supported via the ternary ?: operator.
